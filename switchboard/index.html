A FEW THINGS TO KNOW

Before you
connect.

Setup, privacy, and what runs where.

Read the docs
What is a Wrapp?
A lightweight app that uses Switchboard to connect to your AI, tools and project context. A Wrapp can be a web interface, a native app or an agent harness built around a particular job.
What do I need to get started?
An Apple Silicon Mac running macOS 13 or later, Switchboard, and a supported AI setup. Connect Claude Code or Codex, or use local models for supported tasks. Web Wrapps also need the browser extension.
Is Switchboard free?
Yes. Switchboard is free for individual users. You use your existing AI account; its pricing and usage limits still apply. Any paid tools you connect retain their own charges.
Do I need another AI subscription for every app?
No. Compatible Wrapps can use the AI you have connected to Switchboard. You choose which apps can access it. Switchboard doesn’t add model capacity or bypass your provider’s limits.
Which AI can I use?
Claude Code and Codex are supported. Local models such as Ollama and Whisper handle supported text and voice tasks. Each Wrapp determines which capabilities it needs.
Can websites use files on my Mac?
Compatible web Wrapps can request access through Switchboard. You choose the projects and resources they may use. A website doesn’t get unrestricted access to your Mac.
Does everything stay on my device?
Switchboard runs on your Mac. When a task uses a cloud model or external connector, the information needed for that request goes to that service. Supported local-model tasks can run on-device.
Does it work with web and native apps?
Yes. Web Wrapps connect through the browser extension; native Wrapps use the local Switchboard connection. Apps need a Switchboard integration—it doesn’t automatically connect every installed app.
Will my existing connectors work?
Wrapps can use supported tools configured in the connected AI runtime, within the access you allow. Availability differs between Claude Code and Codex; connectors from a chat account don’t automatically carry over.
What carries across when I switch apps?
The project context you permit: a brand brief, voice, product notes or other supported files. Compatible Wrapps can read that shared context, and save supported outputs back to the project.
Can I build or distribute my own Wrapp?
Yes. Build an interface or harness that connects through the SDK, then distribute it privately. See the developer page for the quickstart and proposed public publishing, enterprise work and revenue-sharing programmes.
