FAQ

Questions, answered.

Is it really free?+
Yes — every wrapp runs on the AI you already pay for, so there's no per-app charge. Pro only adds team features.
Do I need a Claude subscription?+
Yes, signed in through Claude Code on your machine — that's the AI your wrapps run on. No CLI yet? Install @anthropic-ai/claude-code, then run claude to log in.
Is it allowed to run on my Claude plan?+
It runs on your own machine through Anthropic's official Claude Agent SDK — your own sign-in, no shared or resold key. Usage counts against your plan, like any terminal session. Prefer pay-as-you-go? Point it at an API key or a local model instead.
Where does my data actually go?+
Nowhere new. Everything runs on your machine, behind one consent screen. A wrapp gets a result — never your keys or the folder behind them. Open source (MIT), so you can verify every line.
Can I use a local model instead?+
Yes — point it at Ollama, LM Studio, or llama.cpp. A wrapp calls the same interface and can't tell the difference. Fully offline if you want.
